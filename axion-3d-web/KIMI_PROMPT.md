# Промпт для Kimi 3D Web

В Kimi 3D Make выбери именно **3D Web** (не 3D Modeling и не 3D Printing), если нужен интерактивный сайт.

> Создай премиальный интерактивный 3D-сайт на русском языке, посвящённый устройству реактивного турбинного двигателя. Стиль: темный инженерный музей, холодный металл, бирюзовые световые акценты и тёплая подсветка камеры сгорания, минималистичная типографика как у современных промышленных product showcase. Главный объект — подробно проработанная 3D-модель турбины с лопатками компрессора, камерой сгорания, валом, турбинной ступенью и соплом. Модель можно вращать пальцем/мышью на 360°, приближать и удалять. Обязательно реализуй плавную exploded view (ползунок разнесения узлов), выбор каждой детали по нажатию, информационную панель с подписями, запуск и остановку вращения роторов, кнопку сброса камеры. Макет адаптивен для телефонов, планшетов и десктопа; на мобильном 3D занимает основной экран, управление крупное. Используй Three.js и React + TypeScript, ленивую загрузку ресурсов, ограничение pixel ratio для Android, и корректное освобождение ресурсов. Дай полный исходный код проекта и инструкции для самостоятельного деплоя на Cloudflare Pages, а не только ссылку на просмотр. Если узел визуально художественный, явно отмечай, что размеры условные. Сначала сделай качественную модель и управление, затем добавь декоративные эффекты; не ухудшай FPS ради свечения.

Этот промпт даёт творческое направление; возможность экспорта исходников надо проверить в полученном результате.
