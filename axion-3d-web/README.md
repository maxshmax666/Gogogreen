# AXION XR–9 — интерактивный 3D-сайт

Готовый прототип 3D-сайта по мотивам современных интерактивных промышленных 3D-экспозиций. Модель турбины **процедурно создаётся кодом**, без файлов `.glb`. Веб-сайт использует Three.js через CDN, ничего устанавливать не нужно.

## Запуск

* Открыть `index.html` в современном браузере (при первом запуске нужен доступ к CDN `cdn.jsdelivr.net`).
* Надёжнее запускать с HTTP-сервера: `python3 -m http.server 8080` и открыть `http://localhost:8080`.
* Для Termux: `pkg install python -y && python -m http.server 8080 --bind 0.0.0.0`.
* Для публикации: загрузить `index.html` в корень GitHub Pages или Cloudflare Pages. Сборка не нужна.

## Управление

* Вращение — перетаскивание одним пальцем / мышью.
* Масштаб — два пальца / колесо мыши.
* Нажатие на компонент — описание.
* Ползунок — разборка по оси.
* Скорость — частота вращения роторов.
* Кнопка «Пауза» — остановить анимацию.
* «Сброс вида» — вернуть ракурс и положение узлов.

## Важно

* **Это художественная 3D-концепция, не инженерная CAD-модель.** Геометрия, число лопаток и пропорции условные.
* Сайт не требует серверных API и не собирает пользовательские данные.
* Шрифты Manrope и DM Mono загружаются с Google Fonts; при отсутствии доступа используются системные.
* Three.js загружается по сети через CDN; для полностью офлайн-сборки нужно локально разместить зависимости либо перенести проект в Vite.
* Чтобы встроить **настоящую модель** из Blender/Kimi, лучше использовать файл `.glb` и `GLTFLoader`, а не пытаться вручную повторять сложную геометрию.

## Production-путь (TypeScript/React)

1. `npm create vite@latest axion-3d -- --template react-ts`
2. `cd axion-3d && npm install three @types/three @react-three/fiber @react-three/drei`
3. Перенести сцену в `src/scene/Engine.tsx`, интерфейс — в `src/App.tsx`.
4. Заменить процедурную модель на оптимизированный `.glb` с именованными узлами, если потребуется геометрическая точность.
5. Установить лимит DPR для Android и измерить производительность на реальном устройстве.

Подробности: https://r3f.docs.pmnd.rs/ и https://threejs.org/manual/pages/loading-3d-models.html
